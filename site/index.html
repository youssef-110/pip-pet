The desk pet for Claude Code.

Pip stands in the corner of your screen, the same way it is standing in the corner of this page. It watches every Claude Code session you have open and tells you the moment one is done, or when Claude is waiting on you.

Download for Windows Pick a character

Free and open source. Windows 10 and 11. Nothing leaves your machine.

Three things Pip tells you

Still on it

While Claude is thinking or running tools, Pip opens a tiny laptop and types along. One glance at the corner of your screen and you know not to interrupt.

All done

The second a session finishes, Pip hops, makes a soft sound, and shows which project it was along with the last line Claude wrote.

Come here

A permission prompt, or a question only you can answer. Pip waves and keeps waving until you come back, so a session never sits for an hour waiting on a yes.

It turns up when Claude does

Open the Claude desktop app, or start claude in a terminal, and Pip turns up and waves. Close the last one and it waves goodbye and leaves.

Go fullscreen for a film, a game or a call and it ducks out of sight, no goodbye needed. It comes back over fullscreen for two reasons only: a session finished, or Claude is waiting on you.

These switches follow the same rules as the app. Flip them and watch the corner.

Set up once, then forget it is there

  1. Install Pip

    One installer. Pip settles into the corner of your screen and the system tray, and starts with Windows.

  2. It connects itself

    Pip adds a few hooks to ~/.claude/settings.json. Events go to 127.0.0.1 only. Remove them from the menu whenever you like.

  3. Run Claude anywhere

    Any terminal, any project, as many sessions as you want. Open Pip from the tray to change character, colour or outfit.

Works the same on a Claude subscription and on an API key, because Pip listens to Claude Code itself, not to your account.
