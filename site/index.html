The desk pet for Claude Code

Pip sits in the corner of your screen and watches every Claude Code session you have open. It tells you the moment one is done, or when Claude is waiting on you.

Download for Windows Pick a character

Free and open source. Windows 10 and 11. Nothing leaves your machine.

Three things Pip tells you

    
One glance at the corner of your screen, and you know whether to keep waiting.

    

      

        

        
Still on it

        
While Claude is thinking or running tools, Pip opens a tiny laptop and types along. You know not to interrupt.

      

      

        

        
All done

        
The second a session finishes, Pip hops, plays a soft chime and shows which project it was, with the last line Claude wrote.

      

      

        

        
Come here

        
A permission prompt, or a question only you can answer. Pip waves until you come back, so a session never sits idle for an hour.

      

    

  


  

    

      
It turns up when Claude does

      
Open the Claude desktop app, or start claude in a terminal, and Pip pops up and waves. Close the last one and it waves goodbye and leaves.

      
Go fullscreen for a film, a game or a call and it ducks out of sight. It comes back over fullscreen for two reasons only: a session finished, or Claude is waiting on you.

Every session, one glance

      
Run Claude in five terminals across five projects. Each session gets a dot under Pip.

      
Hover the pet and you see what every one of them is doing. This panel is a live demo of that list.

    

    

      

      

    

  


  

    
Set up once, then forget it is there

    
    
      
  1. Install Pip
    One installer. Pip settles into the system tray and starts with Windows.
    2. 
      
  2. It connects itself
    Pip adds a few hooks to ~/.claude/settings.json. Events go to 127.0.0.1 only. Remove them from Settings whenever you like.
    3. 
      
  3. Run Claude anywhere
    Any terminal, any project, as many sessions as you want. Open Pip from the tray to change character, colour or outfit.
    4. 
    

    
Works the same on a Claude subscription and on an API key, because Pip listens to Claude Code itself, not to your account.
